The annotated relationship is helpful because it is hitting correspondences that facilitate group editing. In these slides, we have an evolving formation of rectangles that are all white. Now if we wanna do edit to say turn all of them (their fill) into red, it's gonna be a **lot** of clicks! If we instead organize them under an attribute link that says they are sharing the same color value for the fill attribute, someone working on the editing could much more easily figure out what are the set of rectangles that should change, given some natural language instruction such as "let's change the rectangles in this evolving formation sequence red pls". The scope of the attribute linking relationship matters: there are certainly other boxes with the same fill in the rest of this slide deck, but for this snippet it makes sense that this particular set of boxes in this particular set of slides **should** share values because they are meaningfully related to one another, but not to (for example) some other box that is serving a different purpose (e.g. an icon a the top right corner, the container for some text etc.), even if it happens to have the same fill value.
